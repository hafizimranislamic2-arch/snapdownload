Paste the direct media-file address into the box above. A normal social post URL is not a direct file link.

Your browser opens the file address. Use the browser’s download option when the source makes the file downloadable.

Important: respect creators’ rights

SnapDownload does not extract videos from YouTube, TikTok, Facebook or Instagram, bypass platform restrictions, or remove DRM. Download only when you own the content or have clear permission and the source’s terms allow it.
